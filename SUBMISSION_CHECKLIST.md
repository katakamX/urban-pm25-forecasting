# Final submission checklist

1. Download the Kaggle dataset and place `city_day.csv` in `data/raw/`.
2. Create a Python 3.10/3.11 environment and install `requirements.txt`.
3. Run `python run.py`.
4. Verify `outputs/metrics.csv` contains all expected city/model/horizon rows.
5. Review `outputs/figures/` and `outputs/model_diagnostics.md`.
6. Transfer the actual values from `outputs/metrics.csv` into Section 5.1 of `REPORT.md`.
7. Add the generated output folder to the submission ZIP if your instructor expects run evidence.
8. Keep the source CSV's attribution and original license terms with your submission.

Do not claim a model is best without checking the actual generated metrics. Do not present this historical benchmark as a current live forecast.
